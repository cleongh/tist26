# Learned Rules Directory

This directory contains rules learned via **ILASP** (Inductive Logic Programming).

Per LOGIC_DESIGN.md Section 3.1:
- **Learned Rules** are priority layer 2 (between story and universal)
- These rules are inferred based on repeated patterns or contradictions
- Learned rules are **scoped to the story** and **versioned**

## How Rules Are Generated

1. The `LearningAdapter` observes violations across chapters
2. Patterns are identified (repeated violations, exceptions)
3. ILASP learning tasks are generated
4. ILASP produces new rules
5. Rules are saved here with story scope and version

## File Naming Convention

```
<story_id>_v<version>_<rule_type>.lp
```

Example:
```
harry_potter_v1_ghost_exception.lp
```

## Rule Content

Each file contains:
- Header comments with provenance (source task, timestamp)
- ASP rules learned from the story
- Optional: examples that led to learning

## Important Notes

- **Do not edit these files manually** - they are generated by ILASP
- Rules persist across chapters but are reset per story
- The `RuleRegistry` tracks which rules are active
